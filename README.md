# Claude Code Workspace

Personal workspace for experimenting with Claude Code.

## Getting Started

Clone the repo and open the folder in your terminal or IDE:

```bash
git clone https://github.com/rodrigomendivilf/claude-code-workspace.git
cd claude-code-workspace
```

## Usage

Use this workspace to test Claude Code features, automate tasks, and explore AI-assisted development.
